# What is this project?
A project based on SQLAlchemy made to make runtime querying easier.
## How can this come to a use?
When wanting to create tables/files per user(e.g., In a DBaaS), you have to fill your project with
ugly files.
This project is made for that specific scenario
## How to use it then?
Well, take a look at the tests directory, you can see some basic examples there.
